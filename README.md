# SolidWorks Models

我的 SolidWorks 三维建模作品集（个人练习与课程作业）。

> 仓库以**版本管理**为目的，所有文件均为 SolidWorks 原生格式。
> 总计约 30 MB / 130 个文件，全部远小于 GitHub 单文件限制，**未使用 Git LFS**。

### 独角仙机器人
六足步行机器人，包含斜齿锥齿轮传动箱、曲柄连杆腿部机构、电池安装架与完整标准件库（内六角螺钉、圆柱销等）。

### 四足爬行机器人
四足步行平台，`四足爬行机器人.SLDASM` 为总装配体，`机身部分`／`运动部分` 为子装配体，`engineering-drawing/` 内含工程图。

### 无人机模型
农业植保无人机，含机架、折叠机翼组件、动力装置钣金安装件与控制器安装架。

### 高教杯
按届次整理：`第四届`、`第五届`、`第六届国赛`，以及 `fore`（减速箱）、`two`（CAD 二维）、`three`（调压阀装配体）三组专项练习。

## 装配体使用说明

`.SLDASM` 装配体文件**只保存零件引用关系，不包含零件几何数据**。请按以下方式使用：

- 直接克隆本仓库后，用 SolidWorks 打开 `.SLDASM` 即可，目录结构已保留完整
- 若要单独分享某个装配体，请在 SolidWorks 中使用 **文件 → Pack and Go（打包）** 导出
- 工程图 `.SLDDRW` 同样引用模型文件，请与源零件一起使用

## 环境说明

- 建模环境：**SOLIDWORKS 2026**
- 低版本 SolidWorks 无法打开高版本文件，如需兼容请自行另存为 `.STEP` / `.IGES`

## 关于预览

GitHub **不支持** `.SLDPRT` / `.SLDASM` / `.SLDDRW` 的在线预览与版本比对，点开只能下载。
如需在线查看模型，请将文件另存为 `.STL`（GitHub 内置 3D 查看器，单文件需小于 10 MB）。
