## 更新预览图

GitHub 无法预览 CAD 文件，因此**已完成的项目**都附带 `preview/` 预览图。
新增或修改模型后，可用仓库内脚本重新生成（需本机已安装 SolidWorks）：

```bash
pip install pywin32 Pillow

# 导出某个项目的等轴测预览图，并压到 1000px 宽
python tools/export_previews.py "四足爬行机器人"

# 指定视图 / 宽度 / 只处理部分文件
python tools/export_previews.py "curved-surface" --view front --width 800 --only 杯子
```

脚本会自动跳过无实体、无曲面的空文件，并打印统计报告。

## 装配体使用说明

`.SLDASM` 装配体文件**只保存零件引用关系，不包含零件几何数据**。请按以下方式使用：

- 直接克隆本仓库后，用 SolidWorks 打开 `.SLDASM` 即可，目录结构已保留完整
- 若要单独分享某个装配体，请在 SolidWorks 中使用 **文件 → Pack and Go（打包）** 导出
- 工程图 `.SLDDRW` 同样引用模型文件，请与源零件一起使用

## 环境说明

- 建模环境：**SOLIDWORKS 2026**
- 低版本 SolidWorks 无法打开高版本文件，如需兼容请自行另存为 `.STEP` / `.IGES`

## 关于预览

GitHub **不支持** `.SLDPRT` / `.SLDASM` / `.SLDDRW` 的在线预览与版本比对，点开只能下载。
因此**已完成的项目**都在各自目录下提供 `preview/` 预览图（由 SolidWorks 逐件导出等轴测视图）。
如需在线查看模型，请将文件另存为 `.STL`（GitHub 内置 3D 查看器，单文件需小于 10 MB）。
